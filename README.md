# Paint the Town - GPS Field Trial

Mobile-first Vite/React prototype for a Conshohocken GPS breadcrumb field test.

## Deploy
1. Upload this project to GitHub.
2. Import the repository in Vercel.
3. Deploy with the detected Vite defaults.
4. Open the HTTPS URL on your phone and allow precise location.

## Important
This v0.01 records and paints the raw GPS breadcrumb. It does not yet map-match against an authoritative eligible exploration network. Keep the browser open during the first field test.
